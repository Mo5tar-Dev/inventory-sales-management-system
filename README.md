# Inventory & Sales Management System

A desktop application built with Python using Object-Oriented Programming.

## Features

- Admin and Employee login
- Product management
- Stock management
- Customer management
- Sales history
- Search functionality
- JSON data storage
- Desktop GUI using Tkinter

## Technologies Used

- Python
- OOP
- Tkinter
- JSON
- Pillow
- PyInstaller

## OOP Concepts

- Inheritance
- Encapsulation
- Classes and Objects
